# College Planner

A polished React + Vite college planner with Appwrite authentication and local planner data for tasks, timetable, subjects, attendance and calendar events.

## Tech stack
- React
- Vite
- Tailwind CSS
- Appwrite

## Setup
1. Install dependencies with npm install.
2. Create a .env file using .env.example as a template.
3. Set VITE_APPWRITE_ENDPOINT and VITE_APPWRITE_PROJECT_ID.
4. Start the dev server with npm run dev.

## Environment variables
- VITE_APPWRITE_ENDPOINT
- VITE_APPWRITE_PROJECT_ID

## Build
- npm run build
